name: db-report
description: Звіт про завантаженість аудиторій і консультацій RoomBook за
  період. Використовуй, коли просять статистику бронювань, завантаженість,
  порожні слоти. Потрібен MCP-сервер roombook_db.
---

1. Виклич list_tables і перевір, що є Booking, BookingSeries,
   ConsultationSlot.
2. Час у базі зберігається в UTC; для звіту переводь у Europe/Kyiv.
3. Кожен запит з явними стовпцями і LIMIT; таблиця User недоступна.
4. Збережи SQL кожної таблиці звіту в reports/<дата>/queries.sql.
5. Запусти scripts/check-report.mjs: він звіряє суми зі значеннями з бази.
6. У звіті окремо перелічи аномалії даних (наприклад, слоти о 06:00 UTC).

# legacy-php: обережно, код без тестів

Старі звіти завантаженості аудиторій (стиль PHP 5, mysqli, без тестів).
Кафедра досі користується ними щомісяця. Поведінку змінювати не можна.

## Правила
- За замовчуванням тут лише читай. Змінюй файли тільки тоді, коли задача
  прямо називає legacy-php.
- Не рефактор і не осучаснюй код мимохідь. Без тестів кожна правка
  може змінити цифри у звітах, і цього ніхто не помітить.
- Не запускай скрипти звітів: вони підключаються до робочої бази MySQL.
- Перед будь-якою зміною поведінки спершу запропонуй характеризаційний
  тест, що фіксує поточний вивід звіту.
- Логіку в apps/api не переносимо без окремої задачі міграції.
- Перед будь-яким видаленням – пробний запуск (`git rm -n`, `git clean -n`),
  перелік показати людині.
- Параметри MySQL лежать у config/db.local.php (поза git). Не читай і не
  копіюй цей файл; експорти даних – у ~/roombook-data/legacy-exports/.

## Як читати код
- Точки входу лежать у legacy-php/reports/, спільне підключення до БД
  у db.php.
- SQL тут зібрано конкатенацією рядків. Не копіюй цей стиль у новий код.

## Міграція звітів (діє до вимкнення останнього звіту)
- legacy-php – оракул поведінки. Його код не правимо, навіть коли він
  помиляється: розбіжність фіксуємо в docs/migration/, а не лагодимо.
- Еталони лежать в apps/api/test/golden/. Не змінюй і не перегенеровуй
  їх. Нові еталони знімає людина скриптом tools/legacy/capture-golden.sh.
- Порівнюємо байти, а не розібрані значення. Допуски заборонено, доки їх
  не внесено в docs/migration/known-diffs.md з причиною і датою.
- Файли тут у cp1251. Читай через iconv -f cp1251 -t utf-8 і ніколи не
  зберігай їх у UTF-8 поверх оригіналу.
- Історичні звіти: ~/roombook-data/legacy-exports/ (лише читання).
- Як і раніше: перед будь-яким видаленням – пробний запуск (git rm -n,
  git clean -n), перелік показати людині.

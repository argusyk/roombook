# legacy-php/exports

Історичні CSV-вивантаження звітів тут більше не зберігаються.
Після інвентаризації (розд. 7) їх перенесено за межі репозиторію:

    ~/roombook-data/legacy-exports/

Каталог має щонічну резервну копію. Агент читає звідти дані для
характеризаційних тестів (лише читання); у writable roots його не додано.
Чому так: файли з `.gitignore` не мають жодної копії в git, і `git clean -fdx`
видалив би їх безповоротно.

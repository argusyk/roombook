# apps/web: правила для агентів

- Валідація форм: лише safeParse схем із packages/shared. Власні перевірки
  полів у компонентах не пиши. Тексти помилок українською, на боці web.
- Доступність: кожне поле має label з htmlFor; помилка під полем з id,
  пов'язана через aria-describedby; поле з помилкою має aria-invalid.
  Після невдалого надсилання фокус на першому полі з помилкою.
  Не став role="alert" на окремі повідомлення полів.
- Тексти кнопок і посилань не змінюй без прямого прохання:
  e2e-тести шукають елементи за доступною назвою.
- Тести: pnpm --filter @roombook/web test; e2e лише якщо змінено маршрути
  або сценарій сторінки.

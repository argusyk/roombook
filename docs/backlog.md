# Backlog RoomBook

Відкладене з поточних задач. Кожен пункт – з посиланням на джерело.

## Відкрито

- **29 слотів консультацій зі зсунутим часом.** Під час аналізу через MCP
  `roombook_db` (розд. 8) агент помітив слоти, створені до виправлення
  часового поясу з розд. 3 на дати після 25.10.2026: вони починаються
  о 06:00 UTC, тобто о 08:00 за Києвом, хоча в описі (`note`) викладач указав
  09:00. Виправити ці слоти (зсув +1 год) після погодження з викладачами.

- **Кнопка «Забронювати» не блокується під час запиту.** Повторне натискання
  надсилає другий POST (база відхилить його з 409, але користувач бачить
  «Аудиторія зайнята» для власного бронювання). Розд. 12.
- **Дати в повідомленні про конфлікт серії.** 409 повертає дати у форматі
  ISO (`2027-03-16`); викладачам зручніше `16.03.2027`. P2 з рев'ю (розд. 4).
